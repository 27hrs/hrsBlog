这个博客不追热点，也不保证更新频率，只希望每次打开都像走进一间安静的屋子。

## 关于我

白天写 Java 和前端，晚上读一点书。做过几年业务系统，也做过一些没人用的 side project。相比“把东西做出来”，我现在更在意“它是不是值得存在”。

我相信好的软件应该像好的家具：安静、耐用、不需要说明书。也相信写作是一种整理，把散落的想法放回它们该在的位置。

## 关于这个博客

这里存放长一点的想法：工程、设计，以及生活里值得回看的瞬间。它不试图成为某个领域的权威，只是一份公开的笔记。

技术上，它用 VitePress 做静态生成，内容来自一个很小的 Spring Boot 后端。文章在构建时被同步成 Markdown，所以页面是纯静态的：没有数据库查询，也没有客户端渲染的白屏。

### 写什么

- **工程**：后端设计、前端构建、错误处理，以及那些“看起来很简单”的问题；
- **设计**：排版、颜色、界面里的克制，和照片有关的审美判断；
- **生活**：阅读、散步、旅行，以及一些没有结论的观察。

不写“三天学会”“2026 最火框架”之类的东西。不是它们没有价值，而是这里更适合放慢一点。

## 一些长期在做的事

- 维护一个足够小的内容后端，把复杂度留在该留的地方；
- 练习把界面做得更少，但更准确；
- 每周留半天不安排“产出”；
- 把开了头的项目做完，允许它们“足够好”。

> 写作不是为了被看见，而是为了把看见的东西留下来。
